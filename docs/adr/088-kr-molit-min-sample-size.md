# ADR-088: 서울 월세 — 월세 계약 30건 미만 면적 구간은 기존 값 유지

**상태:** 채택 (2026-11-27)

**맥락:**

`kr_molit.mjs` 는 서울 25개 구의 연립·다세대 월세 계약을 면적 구간 4개로 나눠 구간별 환산 월세
메디안을 낸다 (ADR-087). 2026-10 계약분의 구간별 표본은 다음과 같았다.

| 구간 | 월세 계약 수 | 기존 앱 값 | 계산값 (4.6%) |
|---|---|---|---|
| share (≤10㎡) | 3 | 350,000 | 698,333 |
| studio (11~30㎡) | 2,966 | 650,000 | 771,667 |
| oneBed (31~50㎡) | 2,038 | 1,200,000 | 849,917 |
| twoBed (51~80㎡) | 1,129 | 1,800,000 | 1,076,667 |

share 는 계약 3건의 메디안이다. 시세로 볼 수 없고, 달마다 계약 몇 건이 바뀌면 값이 크게 흔들린다.
그런데도 코드는 표본 수를 보지 않고 값을 갱신 대상에 넣었고, main 정기 실행이 연 자동 PR #82 에
share 698,333 이 실렸다.

**결정:**

1. 구간의 월세 계약 수가 `MIN_SAMPLE_SIZE = 30` 에 못 미치면 그 구간은 갱신하지 않고 기존 값을
   유지한다. 네 구간(share·studio·oneBed·twoBed)에 같은 기준을 쓴다.
2. 건너뛴 구간은 `warnings` 에 구간, 표본 수, 대상 월을 남긴다 (ADR-079 경고 채널, `::warning::`
   annotation). 예: `rent.share: only 3 monthly-rent contracts for 202610 (< MIN_SAMPLE_SIZE 30), keeping existing value`.
   종료 코드에는 영향이 없다. 남은 값은 직전에 검증된 값이기 때문이다.
3. 기준은 `kr_molit.mjs` 의 상수 하나로 둔다. 바꿀 때는 상수, 주석, 테스트, 이 ADR 을 함께 고친다.

**30 을 고른 이유:**

- **메디안의 불확실성을 잴 수 있는 최소 규모다.** 분포를 가정하지 않는 순서통계량 구간으로 보면,
  표본 30건의 메디안 95% 신뢰구간은 정렬한 값의 10번째~21번째 사이다 (포함 확률 95.7%). 3건이면
  최솟값~최댓값 사이도 75% 라서 95% 구간을 만들 수 없다.
- **지금 데이터에서 어느 구간도 경계 근처가 아니다.** share 는 3건이라 지금보다 10배 늘어야 기준을
  넘는다. 나머지 세 구간 중 가장 적은 twoBed(1,129건)도 지금의 3% 미만으로 줄어야 기준에 걸린다.
  월초 정기 실행에서 전달 신고분이 덜 모이거나 일부 구 fetch 가 실패해도 세 구간이 기준에 걸릴
  가능성은 낮다고 본다. 그래서 경계값 하나 때문에 구간이 달마다 갱신·유지를 오가는 일은 지금
  규모에서 생기기 어렵다.
- **흔히 쓰는 기준이라 설명하기 쉽다.** 앞선 조사 보고서도 30건을 예로 들었다. 20·50·100 을 골라도
  2026-10 결과는 같다. 더 엄격한 값을 고를 근거(구간별 월간 변동 실측)는 아직 없다.

**대안 (기각):**

- **share 를 studio 의 일정 비율로 추정** (`ca_cmhc` 의 studio × 0.65 전례) — 실거래가 아닌 추정치라
  출처명에 따로 밝혀야 하고, 비율의 근거도 새로 필요하다. 이번 범위 밖이다.
- **오피스텔·단독/다가구 실거래를 더해 소형 표본을 늘림** — 유형별 전환율도 함께 정해야 해서 범위가
  크다. 이번 범위 밖이다.
- **표본 부족이면 errors 로 남김** — 기존 값은 유효하므로 warnings 가 맞다 (ADR-079). errors 로 두면
  share 처럼 늘 부족한 구간 때문에 다른 구간 갱신이 없는 달에 `isTotalFailure` 로 빨간불이 된다.

**결과:**

- 다음 실행부터 서울 share 는 기존 값(2026-11-27 main 기준 350,000)으로 남고, 매 실행마다 표본
  수가 warning 으로 보인다. studio·oneBed·twoBed 는 ADR-087 대로 갱신된다.
- share 값 자체는 초기 시드 그대로라 실거래로 검증된 값이 아니다. 표본을 늘리는 방법(위 대안)은
  별도 결정으로 다룬다.
- 다른 fetcher 에는 적용하지 않는다. 이 규칙은 `kr_molit.mjs` 에만 있다.
