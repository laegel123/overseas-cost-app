# ADR-074: Compare hero 문구를 "월 지출" 이 아닌 "항목 단가 합" 으로 정정

**상태:** 채택 (2026-09-07)

**맥락:**

Compare hero 는 세 곳에서 합계를 "가계의 월 지출" 처럼 읽히게 표기하고 있었다.

- 가운데 caption: `+27.7만원/월` — 서울합과 도시합의 차액에 `/월` 접미사
- 좌측 하단 footer: `평균 가정 기준`

그러나 `seoulTotal` / `cityTotal` 은 각 카테고리 JSON 의 **항목 단가를 더한 값**이다.
예를 들어 food 는 우유 1L·계란 12개·쌀 1kg 같은 장바구니 단가의 합이지 한 가구가
한 달에 실제로 지출하는 식비가 아니고, transport 는 정기권·1회권 단가이지 실제
이용량을 반영한 월 교통비가 아니다. 소비량·가구원 수·구매 빈도 어느 것도 모델에
없다 (`docs/DATA.md` 의 스키마에 수량 필드 자체가 없다).

따라서 `/월` 과 `평균 가정 기준` 은 **데이터가 뒷받침하지 못하는 주장**이다. 실제
가계 지출과 몇 배씩 차이 날 수 있고, 사용자가 이 숫자를 예산으로 오독하면 이주
준비 판단을 그르친다. 반면 이미 Detail 화면(navy hero)은 같은 성격의 값에
`항목 단가 합` 이라는 정직한 footer 를 쓰고 있어, 두 화면의 문구가 서로 어긋나
있었다.

`docs/PRD.md` F3 는 "평균 가정 기준임을 명시 (작은 캡션)" 을 요구하지만, PRD 작성
시점에는 소비량 기반 가정값 모델(부록 C 의 "가정값 설명 시트")을 전제했다. v1.0 은
그 모델을 구현하지 않았으므로 PRD 문구를 그대로 따르면 사실과 다른 표기가 된다.
PRD 는 수정 금지 문서이므로 본 ADR 로 이탈을 기록한다.

**결정:**

1. **footer** `평균 가정 기준` → **`항목 단가 합`**. Detail navy hero 와 동일 문구로
   통일한다. 문구를 제거하지 않고 교체하는 이유는, 캡션을 지우면 좌·우 값
   (`47.3만원` / `75만원`) 과 배수(`↑1.6×`) 의 정체를 알려주는 단서가 화면에서
   완전히 사라져 오독 위험이 오히려 커지기 때문이다.
2. **가운데 caption** 에서 `/월` 접미사만 제거 — `+27.7만원/월` → **`+27.7만원`**.
   차액 정보 자체는 유지한다. ADR-062 §4 가 서울합=0 (rent/food/transport 전부 OFF
   + 서울 측 데이터가 없는 tuition/tax/visa 만 ON) 케이스에서 `centerMult` 를
   숨기고 **caption 만으로 비교 정보를 전달**하도록 설계했으므로, caption 을 통째로
   지우면 그 상태의 hero 가운데가 빈다. ADR-062 는 그대로 유효하다.
3. 좌·우 값(`formatKRW(total)`) 은 이미 `/월` 을 붙이지 않으므로 변경 없음.

**결과:**

- Compare 와 Detail 의 hero footer 문구가 `항목 단가 합` 으로 일치한다.
- 앱 전체에서 `평균 가정 기준` 문자열이 사라진다 (회귀 방지 테스트로 고정).
- PRD F3 의 "평균 가정 기준임을 명시" 요구와 구현이 갈린다 —
  `docs/UI_GUIDE.md` 상단 편차표 · `.maestro/PLAN.md` 편차표에 기록.
- 디자인 원본(`docs/design/README.md` §3, `docs/design/hifi/compare.jsx`) 의
  `평균 가정 기준 · ❓ 자세히` 는 **원본 명세로 보존**한다. 미구현 ❓ 시트와 함께
  편차표가 차이를 관리한다.
- 소비량 기반 "예상 월 지출" 을 제공하려면 별도 가정값 모델(가구원 수·구매 빈도)이
  필요하다. v1.x 이후 과제이며, 그때 PRD F3 부록 C 와 함께 재검토한다.

**대안 (기각):**

- **caption·footer 모두 삭제** — 문구는 정직해지지만 남은 숫자의 정체를 설명할
  단서가 사라지고, ADR-062 의 서울합=0 fallback 도 깨진다.
- **caption 을 서울합=0 일 때만 표시** — 동작이 조건부라 복잡해지고, 평상시에도
  유용한 차액 정보를 잃는다.
- **PRD 수정** — PRD 는 단일 출처·수정 금지 (CLAUDE.md).

**검증:**

- `app/compare/__tests__/[cityId].test.tsx` — hero footer 가 `항목 단가 합` 이고
  `평균 가정 기준` 이 없으며, hero 하위 어떤 텍스트도 `/월` 로 끝나지 않음.
- 기존 ADR-062 서울합=0 테스트 — caption(`+N만원`) 이 여전히 노출됨.
