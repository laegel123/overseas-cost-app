# ADR-082: `ca_statcan` 실시간 CPI 임시 비활성 (ADR-032 예외)

**상태:** 채택 (2026-11-09)

**맥락:**

2026-11-08 자동 가격 갱신(PR #64, 닫음)이 밴쿠버 식재료를 약 2배로 올렸다. StatCan WDS 로 직접
조회한 결과 `CPI_VECTORS` 21개가 모두 잘못됐다.

- 밴쿠버 7개: 존재하지만 **캐나다 전국의 다른 품목** (우유→과일, 외식→남성복, 카페→신발).
- 몬트리올 cafe: 전국 All-items. 나머지 몬트리올 6개·토론토 7개: 존재하지 않는 vector.

공식도 틀렸다. `cpiToPrice` 는 `지수/100 × STATIC_PRICES` 인데 `STATIC_PRICES` 는 기준년도 가격이
아니라 **현재 시장가**이고, 표 18-10-0004 는 2002=100 이라 벡터가 맞아도 약 2배가 된다.
`isCpiBasePeriodSuspect` 는 경고만 남기고 `ALLOWED_REFERENCE_PERIODS` 가 2002=100 을 허용한다.

**결정:**

재구현 전까지 `refresh()` 는 `allowLiveCpi` 없이는 StatCan 을 호출하지 않고 `STATIC_PRICES` 를 쓴다.
`_run.mjs` 는 이 옵션을 넘기지 않으므로 cron 은 항상 정적값이다. 현재 데이터가 이미 정적값이라
사용자에게 보이는 값은 바뀌지 않는다. 출처명 `(정적 추정치)` 로 사실대로 표시된다.

**대안:**

- **vector 만 교체** — 공식 오류가 남아 값이 여전히 틀린다. 기각.
- **워크플로우 step 제거** — 스크립트를 수동 실행하면 잘못된 값이 다시 들어온다. 기각.
- **실시간 코드 삭제** — 재구현 때 재사용할 fallback·검증 경로와 테스트를 잃는다. 기각.

**결과:**

- 캐나다 3도시 식비는 재구현 전까지 물가 변동을 따라가지 않는다 (ADR-032 의 임시 예외).
- **후속:** 도시 단위 품목 CPI 존재 여부 확인(표 18-10-0004 의 CMA 범위) → 올바른 vector 재매핑 →
  `현재값 = 기준시점 가격 × (최신 지수 / 기준시점 지수)` 로 공식 교체 → 이 ADR supersede.
