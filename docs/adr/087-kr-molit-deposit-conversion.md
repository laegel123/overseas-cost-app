# ADR-087: 서울 월세 = 보증금 환산 월세 메디안 — 전환율 한국부동산원 서울 연립·다세대 4.6%

**상태:** 채택 (2026-11-27)

**맥락:**

PR #75 로 `kr_molit.mjs` 가 국토교통부 연립·다세대 전월세 실거래가 API 응답을 처음으로 제대로
읽었다. 2026-10 계약분으로 계산한 값은 share 65만 · studio 45만 · oneBed 45만 · twoBed 50만원으로,
방 크기가 달라도 값이 거의 같았다. 코드는 계약의 **월세 금액만으로** 구간별 메디안을 냈다.

한국 월세 계약은 보증금 크기가 제각각이다. 같은 실제 응답(2026-10, 25개 구, 전세 포함 10,026건)을
구간별로 나눠 보면 원인이 드러난다.

| 구간 | 월세 계약 수 | 월세만 메디안 | 보증금 메디안 | 보증금 1억 이상 비율 |
|---|---|---|---|---|
| share (≤10㎡) | 3 | 65만 | 1,000만 | 33% |
| studio (11~30㎡) | 2,966 | 45만 | 5,000만 | 38% |
| oneBed (31~50㎡) | 2,038 | 45만 | 7,500만 | 46% |
| twoBed (51~80㎡) | 1,129 | 50만 | 1억 3,000만 | 61% |

면적이 커질수록 주거비가 월세가 아니라 보증금으로 옮겨 간다. 예를 들어 보증금 2억 4,500만 ·
월세 35만 · 40.96㎡ 같은 반전세가 섞이면, 월세만 보는 메디안은 실제 주거비보다 낮게 나온다.

**결정:**

1. 계약마다 **환산 월세 = 월세 + 보증금 × 전환율 ÷ 12** 를 계산하고, 이 값의 구간별 메디안을
   `rent` 로 쓴다. 전세(월세 0)는 지금처럼 집계에서 뺀다. 보증금 태그가 없는 item 은 환산할 수
   없으므로 제외한다. 보증금 0(무보증 월세)은 유효한 계약으로 남긴다.
2. 전환율은 **한국부동산원 전국주택가격동향조사 「지역별 전월세 전환율_연립/다세대」 서울 2026년 9월
   4.6%** 를 상수 `DEPOSIT_CONVERSION_RATE = 0.046` 으로 둔다. 국가승인통계 제304004호이고, R-ONE
   통계표 ID 는 `A_2024_00157`
   (`https://www.reb.or.kr/r-one/portal/stat/easyStatPage/A_2024_00157.do`)이다.
   익익월 15일에 공표하므로 2026-11-27 기준 최신 월은 9월이다.
3. 전환율을 API 로 매번 받아 오지 않는다. 상수를 바꿀 때는 이 ADR, `kr_molit.mjs` 의 주석,
   테스트를 함께 고친다.

**후보 비교 (2026-10 실제 응답에 적용한 구간별 메디안, 원):**

| 전환율 | 근거 | share | studio | oneBed | twoBed |
|---|---|---|---|---|---|
| (환산 안 함) | 지금 코드 | 650,000 | 450,000 | 450,000 | 500,000 |
| **4.6%** | **한국부동산원 서울 연립·다세대 2026-09 (채택)** | **698,333** | **771,667** | **849,917** | **1,076,667** |
| 5.0% | 법정 상한, 2026-10 계약 시점 (기준금리 3.00% + 2%p) | 701,667 | 799,167 | 883,333 | 1,125,000 |
| 5.25% | 법정 상한, 2026-11-26 이후 (기준금리 3.25% + 2%p) | 703,750 | 818,750 | 903,125 | 1,156,250 |
| 6.0% | 참고 (한국부동산원 서울 종합주택 2026-09 은 5.6%) | 710,000 | 850,000 | 950,000 | 1,250,000 |

법정 상한(5.0%)을 쓰면 4.6% 보다 studio +3.6%, oneBed +3.9%, twoBed +4.5% 높다. 5.25% 면
+6.1% / +6.3% / +7.4% 다. 종합주택 5.6% 는 따로 계산하지 않았다. 값은 5.25% 행과 6.0% 행 사이다.

**고른 이유:**

- **표본과 같은 대상이다.** `RTMSDataSvcRHRent` 는 서울 연립·다세대 계약이다. 한국부동산원 연립·다세대
  서울 전환율은 같은 유형, 같은 지역에서 관찰된 시장 전환율이다. 종합주택(5.6%)은 단독주택이 섞여
  있고, 아파트(4.8%)는 다른 유형이다.
- **면적 구간마다 다른 전환율을 쓸 필요가 없다.** 같은 조사의 「규모별 전월세 전환율_연립/다세대」
  (`A_2024_00160`) 에서 서울은 2026-09 에 30㎡ 이하 · 30~60㎡ · 60㎡ 초과가 모두 4.6% 다.
- **값이 안정적이다.** 2025-12 ~ 2026-09 서울 연립·다세대는 4.6~4.8% 사이였다. 상수로 두어도 오래
  어긋나지 않는다.
- **법정 상한은 시장 전환율이 아니다.** 주택임대차보호법 제7조의2 와 시행령 제9조는 계약 기간 중
  보증금을 월세로 바꿀 때의 상한(연 10% 와 기준금리 + 연 2%p 중 낮은 값)을 정한다. 상한일 뿐
  실제 거래의 전환율이 아니다. 또 기준금리가 바뀔 때마다 달라진다(2026-11-26 에 3.00% → 3.25%).

**대안 (기각):**

- **법정 상한 산식(기준금리 + 2%p)** — 위 이유로 기각. 비교 값은 위 표에 남긴다.
- **전세 계약도 환산해 포함** — 2026-10 응답으로 계산하면 studio 785,000 · oneBed 839,500 · twoBed
  1,061,833 으로 결과가 거의 같다. 바꿀 이유가 약하고 범위가 커지므로 지금처럼 월세 계약만 쓴다.
- **신규 계약만 집계 (갱신 제외)** — studio 748,333 · oneBed 845,000 · twoBed 1,083,333 으로 역시
  비슷하다. 이번 범위 밖.
- **전환율을 R-ONE Open API 로 매달 받기** — 인증키와 새 fetcher 가 필요하다. 값이 안정적이라 지금은
  상수로 충분하다. 필요하면 별도 ADR 로 다룬다.

**결과:**

- 다음 정기 실행부터 서울 rent 는 위 표의 4.6% 행과 비슷한 값이 된다. 현재 앱 값(초기 시드
  share 35만 · studio 65만 · oneBed 120만 · twoBed 180만) 대비 +99.5% / +18.7% / −29.2% / −40.2% 라서
  outlier PR 로 온다. 값을 검토한 뒤 병합한다.
- **교차 확인:** 같은 조사의 서울 연립·다세대 2026-10 중위 월세 60만 · 중위 보증금 4,300만원
  (`A_2024_00106`·`A_2024_00105`)을 4.6% 로 환산하면 약 76.5만원이고, 평균(68.4만 · 6,144만원,
  `A_2024_00104`·`A_2024_00103`)으로는 약 92만원이다. 환산 결과 studio 77만 ~ twoBed 108만원은 이 범위와
  어긋나지 않는다.
- **남은 한계:** share(10㎡ 이하) 는 25개 구를 합쳐 월세 계약 3건이라 통계로서 의미가 거의 없다.
  표본은 연립·다세대뿐이며 오피스텔과 단독·다가구는 들어가지 않는다. 둘 다 이 ADR 범위 밖이다.
- 출처 화면(`/sources`)의 서울 rent 출처는 국토교통부 실거래가 공개시스템 하나로 그대로 둔다.
  전환율 출처는 코드 주석, 이 ADR, `DATA_SOURCES.md` 에 남긴다.
