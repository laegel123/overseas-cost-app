## 3. 자세한 설명 (4000자 이내)

```
🌍 살까말까 — 서울 사는 한국인을 위한, 가장 직관적인 해외 생활비 비교 앱.

"밴쿠버 유학 가면 한 달에 얼마 들까?"
"도쿄 취업하면 서울 대비 실수령은 얼마나 차이날까?"
"파리 학비, 셰어 월세, 식비, 교통비 합치면 얼마?"

해외 유학·이주 준비를 시작했지만 정보가 블로그·카페·유튜브에 흩어져 있어 답답하셨다면,
이 앱이 그 모든 단편을 **서울 기준 1:1 비교**로 정리해 드립니다.


■ 핵심 기능

• **서울 vs 해외 도시 1:1 비교**
  20개 해외 도시(아래 목록)와 서울을 항목별로 나란히 비교합니다.
  "한 달 예상 총비용" 을 상단에 한눈에 표시하고,
  학비 · 월세 · 식비 · 교통 · 세금 · 비자 카테고리별로 세부 차이를 보여줍니다.

• **유학생/취업자 페르소나 모드**
  유학생: 학비 + 셰어 월세 + 식비 중심
  취업자: 1인용 월세 + 세금/실수령 + 식비 중심
  "아직 모름" 모드는 두 페르소나의 정보를 모두 보여줍니다.

• **항목별 포함/제외 토글**
  내 케이스에 맞지 않는 항목(예: 비자 면제 국가, 자가 거주)을 끄면
  "내 한 달 예상 비용" 합계가 즉시 재계산됩니다.

• **즐겨찾기 · 최근 본 도시**
  관심 도시를 즐겨찾기에 저장하고, 최근 본 5개 도시를 빠르게 다시 열어볼 수 있습니다.

• **실시간 환율 자동 적용**
  매일 자동으로 환율을 갱신해 모든 비용을 원화(₩)로 환산합니다.
  네트워크 차단 시에는 직전 캐시 기준으로 계산하고 그 사실을 명시합니다.


■ 신뢰할 수 있는 데이터, 항상 공개되는 출처

본 앱이 표시하는 모든 비용 정보는 **공공 통계와 공식 기관 발표** 만을 기반으로 합니다.
- 각국 공식 통계청 (한국 KOSIS·국토교통부, 미국 BLS·Census·HUD, 영국 ONS,
  일본 e-Stat, 프랑스 INSEE, 독일 Destatis, 싱가포르 SingStat, EU Eurostat 등)
- 공식 정부 페이지 (이민국·비자 안내)
- 공식 교통공사·공식 대학 등록금 페이지

상업 비교 플랫폼(Numbeo·Expatistan·Zillow·Yelp 등)은 약관상 사용하지 않습니다.

데이터는 **공공 출처에서 자동으로 정기 갱신**됩니다:
- 환율: 매일
- 식료품·생필품 가격: 매주
- 임차료: 매월
- 교통·학비·비자: 분기 1회

각 카테고리의 출처와 마지막 갱신 일자는 앱 설정에서 바로 확인할 수 있습니다.


■ 개인정보, 수집하지 않습니다

- 회원가입 · 로그인이 없습니다.
- 사용자 정보를 외부 서버로 전송하지 않습니다.
- 페르소나·즐겨찾기·최근 본 도시는 **사용자 기기 내부**에만 저장되며, 앱 삭제 시 함께 삭제됩니다.
- 분석 도구·광고 식별자·추적 SDK 를 일절 사용하지 않습니다.


■ 수록 도시 (서울 + 20개)

🇺🇸 미국: 뉴욕 · 샌프란시스코 · 시애틀 · 로스앤젤레스 · 보스턴

본 앱이 표시하는 정보는 **참고용** 이며, 실제 비용은 시점·지역·개인 상황에 따라

laegel1@gmail.com 으로 보내주세요. 모든 메일을 직접 읽고, 가능한 빠르게 답장 드립니다.
데이터 정정 요청 · 새 도시 추가 요청 · 기능 제안 환영합니다.
```

## 5. 스크린샷 캡션 (5장, 9:16 권장)

각 스크린샷에 한국어 캡션 오버레이를 1줄 추가하면 Play 검색 결과·상세 페이지에서 가독성이 좋아집니다.

| # | 화면 | 캡션 |
|---|---|---|
| 1 | 온보딩 (페르소나 선택) | 유학생·취업자 모드 — 내 케이스 맞춤 비교 |
| 2 | 홈 (도시 검색·즐겨찾기) | 서울 + 20개 해외 도시, 즉시 검색 |
| 3 | 비교 (한 달 총비용) | 서울과 1:1 — 한 달 예상 비용 한눈에 |
| 4 | 상세 (식비 카드) | 라면·우유·계란·백미까지 — 8종 식재료 단위별 가격 |
| 5 | 설정 (출처 보기) | 데이터 출처 항상 공개 — 공공 통계 기반 |

**캡처 권장 디바이스:**
- Pixel 7 시뮬레이터 (1080×2400) — Play Store 의 표준 폰 스크린샷 비율(9:16)에 가장 가까움
- 또는 Galaxy S23 시뮬레이터 (1080×2340)

**캡처 시점:**
- 데이터: 시드 데이터 또는 production URL fetched 상태 (둘 다 동일 결과)
- 페르소나: 유학생 (학비·셰어 월세 카드 노출)
- 도시: 비교 화면은 **서울 vs 밴쿠버** (UI Guide 의 hifi mock 도시) — 일관성
